# Sumit Kumar - Modern Developer Portfolio 🚀

A modern, fast, responsive personal portfolio website built with pure semantic HTML5, CSS3, and JavaScript.

## ✨ Features
- **Zero Database Required**: Direct-to-email contact form powered by FormSubmit AJAX (`sumitkeshri.1237373@gmail.com`).
- **Live Deployed Projects Showcase**: Highlighting production-ready web apps hosted on Vercel and Render.
- **Dynamic Coding Stats**: Live GitHub streak, top languages, and LeetCode problem-solving cards.
- **Modern Dark Aesthetic**: Ambient glows, glassmorphism, responsive navigation, and floating badges.
- **Instant Deployment**: Pure static files ready for GitHub Pages, Vercel, or Netlify with zero build step.

## 🚀 How to Deploy

### Option 1: GitHub Pages (100% Free & Easy)
1. Push this repository to GitHub (e.g. `sumit-2007-git/portfolio`).
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Your site will be live at `https://sumit-2007-git.github.io/portfolio/` in 1 minute!

### Option 2: Vercel
1. Go to [vercel.com](https://vercel.com) and click **Add New Project**.
2. Import your GitHub repository.
3. Click **Deploy**. Done!
